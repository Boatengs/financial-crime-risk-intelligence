# Notebooks

Start with [`01_project_walkthrough.ipynb`](01_project_walkthrough.ipynb).

This folder follows a reviewer-first notebook standard:

- Markdown explains the purpose of each analytical step before the code.
- Code comments explain intent, assumptions, or non-obvious choices rather than narrating obvious syntax.
- Every meaningful output is followed by Markdown explaining what the result shows, why it matters, and any important limitation.
- Ranking, calibration, model-selection, and investigator-review outputs are interpreted as decision support only; they are not evidence of criminal activity or legal conclusions.

The walkthrough summarizes verified project results already documented in the repository, including the structural baseline, node-enriched random forest, edge-feature ablation, calibration trade-offs, and human-review guardrails.
