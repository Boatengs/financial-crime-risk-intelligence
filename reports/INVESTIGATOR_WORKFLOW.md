# Investigator Workflow

The analytical product is a prioritized case queue, not an automated accusation system.

Each case should provide:
1. rank and model risk score,
2. component size and structural statistics,
3. model-derived reason codes,
4. relevant neighboring-flow context when available,
5. an explicit uncertainty/caveat field,
6. links back to reproducible analytical evidence.

Ground-truth benchmark labels are evaluation-only and must not be used as investigator-facing explanations.
